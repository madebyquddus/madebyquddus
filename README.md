# 👋 Hey, I'm Quddus

💻 I build software, design digital experiences, and experiment with AI-assisted development.

🧡 I'm an independent developer and designer working under **MadeByQuddus**. My work spans web development, desktop applications, healthcare-related digital projects, creative tools, and local AI experiments.

🚀 I enjoy taking ideas from concept to working software, exploring how things work under the hood, and building practical tools along the way.

---

## 🛠️ Building

- 🖥️ **MBQ PowerShell Studio** — A Windows application for PowerShell workflows, system monitoring, and developer productivity.
- 🚘 **MBQ Wrap Studio** — A 3D automotive wrap-design workstation in development.
- 🕒 **MBQ PostClock** — A time-zone clock application for coordinating work across different regions.
